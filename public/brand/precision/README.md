# Mockachino Precision logo asset pack

This directory contains the reusable Precision logo asset pack. The source artwork is traced from the approved reference image at `../mockachino-precision-reference.png`.

## SVG masters

- `logo-dark.svg` — gold mark with off-white lettering, for dark backgrounds.
- `logo-light.svg` — gold mark with charcoal lettering, for light backgrounds.
- `mark.svg` — standalone gold mark.

The SVG masters are genuine path-only vectors with flattened colors. They contain no embedded raster images.

## Transparent PNG exports

The PNG exports have transparent backgrounds and live in `png/`:

- `logo-dark-256.png`, `logo-dark-512.png`, `logo-dark-1024.png`, `logo-dark-2048.png`
- `logo-light-256.png`, `logo-light-512.png`, `logo-light-1024.png`, `logo-light-2048.png`
- `mark-16.png`, `mark-32.png`, `mark-48.png`, `mark-64.png`, `mark-128.png`, `mark-256.png`, `mark-512.png`

Use the dark logo on dark surfaces and the light logo on light surfaces. Use `mark.svg` or a corresponding square PNG when only the symbol is needed, such as an avatar or compact icon.
